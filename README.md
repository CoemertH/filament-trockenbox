# Filamentbibliothek – Webausgabe

Dieses Repository enthält ausschließlich die erzeugten Browserdateien. Der vollständige Entwicklungsquellcode und die Tests werden separat privat verwaltet.

Die ausgelieferten Browserdateien bleiben technisch einsehbar. Verkleinerung und Bündelung ersetzen keine Zugriffskontrolle. Die Lizenzbedingungen der enthaltenen Drittanbieter-Bibliotheken stehen in den zugehörigen Lizenzdateien.
